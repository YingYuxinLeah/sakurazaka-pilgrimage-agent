# 3 分钟演示视频脚本

## 0:00–0:20 问题

展示 SakuMap 地点很多，但用户仍需逐个查地图和时间。用一句话说明产品目标：把地点信息转化为能执行的路线。

## 0:20–1:20 多轮 Agent

1. 输入：“我想在港区巡礼。”
2. 展示 Agent 集中补问。
3. 回答：“六本木站，4 小时，不需要用餐，我想限定成员。”
4. 展示 Agent 继续追问具体成员，而不是重复问题。
5. 输入一个存在真实地点的成员名，生成地图路线。

## 1:20–2:05 动态决策

重新开始一轮需要用餐的路线。展示：先找巡礼餐厅；若没有，Agent 请求查询普通餐厅的授权；同意后再规划。

## 2:05–2:35 产品能力

快速切到作品说明或 README，讲清三点：模型负责理解和选工具，后端负责不可违反的规则；地点有来源和更新时间；公开 Demo 有成本限额。

## 2:35–3:00 复盘

展示产品案例中的 MVP、评测与下一步。强调这是从问题定义、原型、Agent 工具设计到上线验证的完整产品闭环。

录屏建议：桌面宽度 1440px；浏览器缩放 90%–100%；关闭通知；鼠标移动放慢；等待动画可剪短；字幕只突出“补问、工具选择、授权、路线结果”。
